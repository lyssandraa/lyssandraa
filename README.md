# Hi, I'm Lysandra 👋

Junior software developer who likes building complete products, from the database to the app in someone's hand.

My main project is a full booking, shop and loyalty platform for a working barbershop: a React website with an admin dashboard, an iOS/Android app in React Native, and an Express + PostgreSQL API behind both. It is live and used by the shop's customers.
